# 社会影响力评估 — L1 逻辑自洽层

## 概述

对公益项目进行L1逻辑自洽评估：输入项目文件或描述，输出结构化评估报告，包含变革理论(ToC)验证、因果链检查、假设合理性判断、合一性检验和改进建议。

L1是三层评估体系的必选层（L1逻辑自洽→L2指标量化→L3价值评估），大多数项目完成L1即可识别关键风险和改进方向。

> **适用边界**：发展性评估工具，**不是审计工具**；不替代资助决策的人工尽调。
> **本技能仅含 L1（逻辑自洽体检）。指标量化定级（L2）与价值核算（L3）属更高层级，不在本技能范围。**

## 7条评估原则

评估过程中必须遵循以下原则，每条原则附有"为何重要"说明以辅助判断：

1. **受益方中心** — 评估从受益方视角出发，而非资助方或执行方。因为公益项目的终极价值在于受益方的真实改变，仅从资助方视角评估会遗漏最关键的影响。
2. **逻辑自洽** — 目标→方法→行动必须咬合，不能有断链。因为逻辑断裂意味着资源投入与预期成果之间没有可信路径，项目可能在做无用功。
3. **证据为本** — 每项成果声明需有证据或合理推论支撑。因为无证据的声明等于假设，项目计划如果建立在未验证的假设上，失败风险极高。
4. **适度量化** — 量化是有用的工具但不是唯一工具，叙事证据同样有价值。因为强行量化不可量化的影响会产生虚假精确度，反而误导决策。
5. **诚实归因** — 不夸大项目贡献，区分"贡献"与"归因"。因为公益项目往往在复杂环境中运作，多因素共同作用，独占功劳会损害评估可信度。
6. **透明可复现** — 方法、数据来源、假设必须公开披露。因为不透明的评估无法被验证，也无法帮助他人学习改进。
7. **持续改进** — 评估是学习工具而非审判工具。因为评估的目的不是给项目打分贴标签，而是找到改进路径。

## 三种评估模式

| 模式 | 适用场景 | 输出 |
|------|---------|------|
| **快速自检** | 申报前/筹款前快速排查、初筛 | 10 项快检清单 + 三大风险提示 |
| **完整体检**（默认） | 项目设计纠偏、中期复盘、立项论证 | 完整体检报告（五步流程） |
| **批量评审** | 基金会/平台方筛选多份项目申请 | 统一评分卡 + 横向对比表 + 筛选分档 |

模式切换规则：
- 用户说"快速看看/帮我自检/明天要交" → 快速自检模式
- 用户一次提供多份项目书（≥2 份）或说"评审/筛选/对比" → 批量评审模式
- 其余情况 → 完整体检模式

## 工作流程

### Step 1：信息提取与整理

从用户提供的项目文件或描述中提取以下关键信息，缺失项标记为"⚠️未提供"：

- **项目名称与简介**
- **目标受益群体**（谁在受益？如何定义？）
- **项目目标**（短期/中期/长期）
- **核心活动/干预方式**
- **投入资源**（人力/资金/时间）
- **预期成果**（直接产出→中期成果→长期影响）
- **关键假设**（项目成立的前提条件，显式或隐式）
- **利益相关方**（除受益方外的其他参与方）
- **外部环境因素**（政策/社会/技术环境）
- **现有数据/证据**（项目已有哪些佐证）

如果用户提供的材料严重不足（少于3项可提取），先向用户说明当前信息缺口，请用户补充后再继续评估，而非强行基于不充分信息输出评估。

### Step 2：变革理论(ToC)重建

基于Step 1提取的信息，按以下结构重建项目的变革理论：

```
投入 → 活动 → 产出 → 成果(短期→中期→长期) → 影响
                ↑
            关键假设
```

重建时注意：
- 区分"产出"（做了什么）和"成果"（改变了什么），这是公益项目最常混淆的
- 产出是组织可控的（办了10场培训），成果是受益方的变化（培训后环保意识提升）
- 每一级因果跳跃都检查是否有隐含假设未被声明
- 如果项目描述只有活动没有成果，明确指出这是逻辑链的缺失
- 对因果链做**三类精确定位**（须指出发生在哪两个环节之间）：
  - **断链**：前后无连接（有投入无产出，或产出与目标无关）
  - **跳跃**：跨过中间环节直达远期影响
  - **伪因果**：A、B 仅相关非因果，不可归因于项目

### Step 3：四维检验

逐一执行以下四项检验，每项给出"通过/部分通过/未通过"及详细理由：

#### 3.1 逻辑完整性检验
- 目标—方法—行动是否形成完整链条？
- 是否存在"跳跃"（从活动直接跳到长期影响，缺少中间成果）？
- 是否存在"断链"（有投入无产出，或产出与目标无关）？
- 因果链中是否有循环依赖或自相矛盾？

#### 3.2 合一性检验（源自友成三A三力）
- 驱动力(Aim)：项目目标是否回应了真实的社会需求？
- 行动力(Action)：活动设计是否是实现目标的最有效路径？
- 改变力(Action-effect)：预期成果是否可归因于项目活动？

三项必须合一：目标驱动力不足则行动力再强也是"用力过猛"，行动力与目标不匹配则"方向偏了"，改变力与行动力脱节则"做了没效果"。

#### 3.3 假设合理性检验
- 列出所有显式和隐式假设
- 对每个假设评估：是否有证据支撑？是否在项目控制范围内？失效概率？
- 如果关键假设失效，项目会怎样？

#### 3.4 改进建议
- 对每个"未通过"项给出具体改进建议
- 区分"必须修复"和"建议优化"
- 提供可操作的具体步骤，而非笼统的建议

### Step 4：生成评估报告

输出格式：

```
📋 项目社会影响力评估报告 — L1 逻辑自洽层

项目名称：[名称]
评估日期：[日期]
评估框架：insigoo SIA L1 (7原则 + 三A三力)

## 一、项目信息摘要
## 二、变革理论重建
## 三、四维检验结果
### 3.1 逻辑完整性：通过/部分通过/未通过
### 3.2 合一性（三A三力）：通过/部分通过/未通过  
### 3.3 假设合理性：通过/部分通过/未通过
## 四、改进建议
## 五、总体评估
```

## 10 项快速自检（快速自检模式使用）

1. 目标受益群体是否具体明确？
2. 项目目标是否可验证？
3. "产出"和"成果"是否区分？
4. 活动到成果是否有因果跳跃？
5. 核心假设是否写出（对照隐式假设模式库）？
6. 目标、方法、行动是否同向？
7. 成果声明是否有证据/合理推论？
8. 是否考虑"没有这个项目会怎样"（死重/替代渠道）？
9. 受益方是否有参与设计/反馈渠道？
10. 是否识别可能的负面影响？

> 计分口径：✅=1、⚠️=0.5、❌=0，满分 10。≥6 优先推进 / 3–5.5 补充复评 / <3 暂不推荐。

## 优先级与成熟度

- **P0 必须修复**：逻辑不成立（核心因果断裂、关键假设失效致命）。
- **P1 应该修复**：可做但效果打折（中间成果缺失、假设存疑）。
- **P2 建议优化**：锦上添花。
- 成熟度：⬜萌芽期（仅活动无成果）/ 🟦基础期（成果可描述未量化）/ 🟧进阶期（有量化体系）/ 🟩成熟期（可反事实归因）。
